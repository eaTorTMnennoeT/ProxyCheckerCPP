================================================================================
                         Proxy Checker Pro v1.0
================================================================================

고속 멀티스레드 프록시 체커 프로그램
HTTP/HTTPS 프록시 검증 및 Chrome 브라우저 연동 지원

================================================================================
                              주요 기능
================================================================================

[프록시 체크]
- 멀티스레드 동시 체크 (최대 100개)
- 타임아웃 설정 가능
- 익명성(Anonymous) 자동 판별
- 외부 IP, 국가, 도시, ISP 정보 조회
- 응답 시간 측정 및 정렬
- 실패 횟수 추적 및 Uptime 표시

[프록시 관리]
- 파일에서 로드 (txt)
- 클립보드에서 붙여넣기
- 작동하는 프록시만 저장/복사
- 실패한 프록시 삭제
- 실패한 프록시만 재체크
- 자동 주기적 체크 (Auto)

[Chrome 연동]
- 선택한 프록시로 Chrome 브라우저 실행
- 인증이 필요한 프록시도 자동 로그인 (팝업 없음!)
- Puppeteer를 통한 안정적인 프록시 인증 처리

================================================================================
                             지원 형식
================================================================================

프록시 형식:
- IP:PORT                          예) 192.168.1.1:8080
- http://IP:PORT                   예) http://192.168.1.1:8080
- http://USER:PASS@IP:PORT         예) http://admin:1234@192.168.1.1:8080

================================================================================
                             사용 방법
================================================================================

1. 프록시 로드
   - [Open File] 버튼으로 txt 파일 열기
   - [Paste] 버튼으로 클립보드에서 붙여넣기

2. 프록시 체크
   - Timeout: 타임아웃 시간 (초)
   - Threads: 동시 체크 수
   - [Start Check] 버튼 클릭

3. 결과 확인
   - Success: 작동하는 프록시 (녹색)
   - Anonymous: 익명 프록시 (녹색)
   - Not Anon: 비익명 프록시 (주황색)
   - Failed: 실패 (빨간색)

4. 프록시 사용
   - 작동하는 프록시 선택 후 우클릭
   - [Open in Chrome] 선택
   - Chrome이 프록시 적용 상태로 실행됨

5. 결과 저장
   - [Copy Working] 작동하는 프록시 클립보드 복사
   - [Save Results] 전체 결과 파일 저장

================================================================================
                             파일 구성
================================================================================

필수 파일:
- ProxyChecker.exe      메인 프로그램
- launch_chrome.js      Chrome 실행 스크립트
- node_modules/         Node.js 모듈 (puppeteer-core)

================================================================================
                              요구 사항
================================================================================

- Windows 10/11
- Google Chrome 브라우저
- Node.js (Chrome 연동 기능 사용 시)
  https://nodejs.org 에서 다운로드

================================================================================
                              단축키
================================================================================

더블클릭     프록시 주소 복사

================================================================================
                              문제 해결
================================================================================

Q: Chrome 실행이 안 돼요
A: Node.js가 설치되어 있는지 확인하세요.
   cmd에서 "node -v" 명령으로 확인 가능

Q: "launch_chrome.js not found" 에러
A: ProxyChecker.exe와 같은 폴더에 launch_chrome.js 파일이 있어야 합니다.

Q: 프록시 체크가 느려요
A: Threads 수를 늘려보세요 (권장: 30~50)

Q: 모든 프록시가 실패해요
A: Timeout을 늘려보세요 (권장: 3~5초)
